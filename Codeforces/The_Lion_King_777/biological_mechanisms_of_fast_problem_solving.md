# The main realization:
Doing experiments one confirms the laws of (human) nature, a human cannot break human's rules... <br/>
In this case, the experiments were done solving a smaller number of problems, but with higher quality (metacognition and reflection). 
These experiments just confirm the laws of nature such as working memory limits, and so on... 
A mastered skill is actually performed significantly less by the Central Executive Network (CEN). As a skill transitions from a 
conscious effort to mastery *(automaticity)*, neural activity shifts away from frontoparietal control networks and toward subcortical 
procedural systems. For mental skills, one of the most important procedural systems is the Basal Ganglia: <br/>

* The command center for procedural memory and habit formation.
* It is divided into the caudate nucleus (handling cognitive sequences and goal-directed actions) and the putamen (handling motor skills and habitual routines).
* It "chunks" separate steps into a single, cohesive unit—meaning you execute a whole sequence (like typing your password) as one fluid motion rather than thinking of each individual letter.

This is exactly what happens when one is aiming for mastery... And again, experiments just confirm these are facts. <br/>
Another important realization is that when someone is in a contest, one has limited time, and obviously one needs to solve problems faster 
in this scenario (and it is not exactly the same behavior as if one has "infinite" time i.e. when one is solving problems but NOT in a contest) 
the **KEY** *bad habit* to replace is to **REDUCE EVERY MOMENT THE SITUATION that one is at, TO A KNOWN/MASTERED SKILL**, the scientific 
justification was given above with the basal ganglia (it prevents cognitive overload): this PREVENTS FROM TOO RANDOM GUESSING AND ALLOWS 
ONLY SIMULATING with (known) SKILLS IN WORKING MEMORY, TESTING IF THE CORRECT SKILL IS BEING USED AT A MOMENT... At the same time 
mastering a set of skills ALLOWS TO *TRY MORE APPROACHES (AND FASTER)* because WE JUST HAVE TO TEST IF THOSE PATTERNS/SKILLS ARE CORRECT 
for the current situation, WE DO NOT HAVE TO CREATE THE SKILLS FROM SCRATCH (which would be a HUGE waste of time in contest time!)... 

## In other words:
In contest time there is NO TIME TO DEVELOP NEW SKILLS, BUT to TEST (AND *REDUCE TO*) A BUNCH OF MASTERED ONES.
