# Most important parts during solving the problem:
* An object can have a lot of representations. In this case one can represent the same object in various ways.
* We call a representation that is Explainable, Predictable and that uses Mathematical tools a Mathematical model.
* In this problem one can apply the concept of *changing* the **Mathematical Model** of the same object until some realization happens (the *Predictable* part).
* The object for which the model was changed in this problem was the one told in the problem statement: the array where the operations were applied using the "jump vector". So **instead** of using NUMBERS to represent that array, **we used HISTOGRAMS/BLOCKS**, and THIS **SUBTLE CHANGE** triggers the *realization* that the sum of the operations is EQUAL to the triangular # of operations performed (which was the CORE IDEA for solving this problem).
