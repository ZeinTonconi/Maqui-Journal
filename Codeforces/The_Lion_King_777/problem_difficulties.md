# Key observation:

Concepts are very big containers, and from these new problem arise... This is obvious because as concepts can be seen as "infinite" there 
are also infinite problems that can be created (that belong to that concept). <br/>

This is why we can see the pattern that in harder problems, they actually use past concepts (that are more abstract than patterns) 
but once the (past) correct concepts are retrieved for a novel problem, then the patterns and algorithms just "fit in" easily! <br/>

So for harder (novel) problems it's more important to "climb to the abstract" rather than "digging deeper".
