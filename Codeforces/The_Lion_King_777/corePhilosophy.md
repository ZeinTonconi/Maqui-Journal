* In a contest one should do a problem that ALREADY KNOWS HOW TO SOLVE.
* In a contest, you don't have time to come up with something completely new and original.
* So, following the previous principle, the only way that this can happen is to USE ALREADY ACQUIRED KNOWLEDGE during the contest time.
* By definition, knowledge is ALL THE PATTERNS that one ALREADY KNOWS.
* So, the ammount of *Accomodation* required to solve a problem in contest time SHOULD NOT BE THAT MUCH.
* The purpose of this github is to help to make myself follow these principles.
