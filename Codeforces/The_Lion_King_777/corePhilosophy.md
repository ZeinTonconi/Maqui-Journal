## Replacing old habits:
Most of the times I feel that I don't search very well in what I already know, and instead I tend to create new things. This is a TRANSFER problem, and by definition, creating newer things is way harder than getting inspired by old building blocks. So fixing this habit to *searching better* in semantic memory is what I feel is more correct.

## And don't forget:
The most important part to develop (and use) is semantic memory because this way we prevent the recency effect (and a lot of, very probably, (bad) mental biases), by structuring information by *meaningful connections* we can build strong knowledge and use it even if *not used very long time ago*.
