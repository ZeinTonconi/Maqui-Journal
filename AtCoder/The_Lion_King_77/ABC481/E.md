# Interesting insight from metacognition:
I was thinking "this is very similar to a problem I've seen before, in that problem I divided the plane into 2 half-planes and then I 
sorted the vectors independently, and then I made a union of them" BUT I DIDN'T REMEMBER THE **EXACT** SOLUTION TO THAT PROBLEM! But the 
interesting observation I made from that is that I was thinking something like "hmm I don't remember, maybe I should try remembering the full 
(old) problem", but THAT WAS THE MISTAKE! <br/>

## Why that was a mistake:
Sometimes, our memory is NOT perfect, so in this example I was trying to *REMEMBER WHAT THE EXACT (OLD) PROBLEM WAS ASKING FOR* why? To 
see if that old problem was the *SAME* or *super similar* to the current problem (TO SEE IF THE SAME SOLUTION CAN TRANSFER A LOT OF INFO TO 
THE PRESENT), and this was a mistake because actually *I WASTED MORE TIME IN "TRYING TO REMEMBER" MODE* instead of *CREATING A NEW SOLUTION* with 
the *PRIMITIVE PIECES* (like the "2 half-planes" idea and mix this with other new ideas to do convergent thinking to solve this problem).

## Why this is a really valuable lesson:
Trying to remember an old solution is very nice because there can be a lot of (positive) transfer to the present task, BUT there can be also 
negative transfer... So I should be conscious about that the next time... I can ask myself: *"Is it valuable to try to remember 
that old solution?"* this question can be answered if I try to remember the details of the OLD problem for some **short time (usually seconds)** 
but if nothing more of the details can be retrieved, usually it is a good idea to *SWITCH TO CREATIVE THINKING MODE* (and instead do 
convergent and divergent thinking, this is the way I solved this problem during contest).

## Short lesson to remember:
If I CANNOT remember the details that I want to remember from some old problem (for some time, usually short time such as seconds), switch to creative mode.
