# What is transfer?
Transfer is the recall of memories used in other contexts in the past, to the present context. <br/>
This is a CORE element in competitive programming because patterns actually repeat in contest problems... To achieve this we can do:
* Specific practice: Using the tool in a specific context.
* See examples where the tool/pattern also applies: Once the tool was used in that specific context, try to see different contexts/examples where the same tool/pattern is used.
* Abstract the tool: Like in maths, one Abstracts the Structure (one *clears the UNNECESSARY COMPONENTS OF THE CONTEXT* to prevent "overfitting" and cause generalization), this means one creates the *MOST IMPORTANT SITUATIONS/CONTEXTS* or a *Situation Model* where the tool can be used to "solve" the situation, and second: CREATE THE PIECE/PATTERN to use it in multiple future scenarios.
* For bigger ideas/concepts/heuristics: Try to even either create *more possible scenarios* where this big concept can be used, or try to clear even more situational components where the tool can be used.
